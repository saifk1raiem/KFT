# Tests

No automated Godot test runner is installed yet. Use this checklist after opening the project in Godot:

1. The project starts at `res://scenes/main/Main.tscn`.
2. The board creates 8 columns and 4 rows.
3. The shop shows five units.
4. Buying a unit spends gold and adds the unit to the bench.
5. Selecting a bench unit and clicking the lower half of the board deploys it.
6. Starting battle resolves combat and shows a result.
7. Ending the round grants income, clears enemies, and rolls a new shop.
