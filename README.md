# KFT

KFT is a realistic medieval 2D auto-battler inspired by the draft-and-team-building feeling of TFT.

Working title: **KFT: Kingdom Fight Tactics**

## Open In Godot

1. Install Godot 4.x.
2. Open this repository folder in Godot.
3. Press Play.

## Godot Prototype

- 8-player match: 1 human and 7 AI opponents.
- Five-card draft shop each round.
- Coins, buying, selling, bench, and board placement.
- Seven unit types from barehand recruit to 5-cost lancer horseman.
- Equipment cards and formation tactic cards.
- Star upgrades from three matching units.
- Auto-combat, HP loss, rewards, penalties, AI drafting, eliminations, victory, and defeat.
